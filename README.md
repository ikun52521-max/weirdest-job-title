A deterministic entry for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty. The program writes a single invented job title — "Senior Apologizer for Self-Driving Cars" — to `entry.txt`. It reads like a real corporate title with one gloriously specific twist: the cars drive themselves, but someone still has to say sorry on their behalf. Same title on every run, no network, Python 3 standard library only.

## Run it

```sh
python3 main.py
```

The title is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
